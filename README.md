# Showzie

A simple and responsive **Movie Website** built using **HTML, CSS, and JavaScript**. The website provides a visually appealing interface for browsing movies and allows users to click on a movie to view its corresponding page on **IMDb**.

## Overview

This project is a frontend-based movie browsing website designed to provide users with an easy and interactive way to explore movies.

The website displays movie information in a clean and organized layout. When a user selects a movie, they are redirected to the respective movie's page on IMDb, where they can find additional information such as ratings, cast, reviews, trailers, and other details.

## Features

* Responsive movie website interface
* Movie cards with posters and movie information
* Interactive movie selection
* Direct redirection to the corresponding IMDb movie page
* Clean and user-friendly design
* Navigation bar for easy browsing
* Search functionality (if implemented)
* Responsive layout for different screen sizes
* Built entirely with frontend technologies
* No backend or database required

## Technologies Used

### HTML5

Used to create the structure and content of the website.

### CSS3

Used for:

* Page styling
* Movie card layouts
* Navigation bar
* Responsive design
* Animations and hover effects

### JavaScript

Used to:

* Add interactivity
* Handle user interactions
* Implement movie selection
* Redirect users to IMDb pages
* Implement dynamic functionality such as search/filtering, if included

## How It Works

1. Open the website in a browser.
2. Browse through the available movies.
3. Each movie is displayed as an interactive movie card.
4. Click on the movie you want to explore.
5. The website redirects you to the corresponding IMDb page.
6. You can then view detailed information about the selected movie on IMDb.

## Installation and Setup

Since this is a frontend-only project, no special installation or server setup is required.

### 1. Clone the Repository

```bash
git clone https://github.com/aditim065/Showzie-Movie-Site.git
```

### 2. Navigate to the Project Folder

```bash
cd your-repository-name
```

### 3. Open the Website

Simply open:

```text
index.html
```

in your web browser.

Alternatively, you can use **VS Code Live Server** to run the project locally.

## Usage

The website can be used to:

* Browse a collection of movies

* Select a movie
* Navigate directly to its IMDb page
